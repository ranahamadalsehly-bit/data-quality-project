# 🏥 مشروع تحسين جودة بيانات المنشآت الصحية وتراخيصها
**دراسة تطبيقية باستخدام عينة افتراضية لأغراض التدريب**

---

## 📋 ملخص المشروع
يهدف هذا المشروع إلى تطبيق مفاهيم إدارة جودة البيانات على عينة افتراضية من بيانات المنشآت الصحية الخاصة وتراخيصها. يتم ذلك من خلال تحديد نطاق البيانات، وتوزيع الأدوار، وفحص البيانات، وتحديد قواعد الجودة، ثم إعداد خطة لمعالجة المشكلات ومتابعة التحسن المستمر.

## 🎯 نطاق المشروع
يقتصر المشروع على مراجعة وتحسين عينة افتراضية تتكون من **20 سجلاً** لمنشآت صحية خاصة، مع التركيز على البيانات التعريفية للمنشأة وبيانات الترخيص، ويشمل الآتي:
- مراجعة اكتمال البيانات وعدم وجود سجلات مكررة.
- التحقق من الدقة والصلاحية والاتساق.
- مراجعة حداثة البيانات (التوقيت).
- تحديد المشكلات وإعداد خطة لمعالجتها.

## 📏 أبعاد وقواعد جودة البيانات

| البُعد | طريقة التحقق |
| :--- | :--- |
| **الاكتمال (Completeness)** | فحص الحقول الفارغة والتأكد من تعبئتها |
| **التفرد (Uniqueness)** | مراجعة التكرار في الرقم الموحد، والتحقق من السجل قبل الدمج أو الحذف |
| **الدقة (Accuracy)** | مطابقة عينة البيانات مع المصدر الرسمي |
| **الصلاحية (Validity)** | فحص تنسيق الأرقام والتواريخ والقيم المسموح بها |
| **الاتساق (Consistency)** | مقارنة حالة الترخيص بتاريخ الانتهاء والتحقق من أي استثناء |
| **التوقيت (Timeliness)** | مراجعة تاريخ آخر تحديث ومقارنته بدورية التحديث المعتمدة |

## 📈 خط الأساس والعتبات (Thresholds)
- **خط الأساس:** وصف الوضع الحالي للبيانات قبل المعالجة.
- **المستهدف:** المستوى المراد الوصول إليه بعد التحسين.
- **العتبة:** الحد الذي يستدعي عنده الوضع اتخاذ إجراء تصحيحي.

### معايير العتبات المقترحة لمتابعة مستوى جودة البيانات:
- 🟢 **مقبول:** `95%` فأعلى.
- 🟡 **يحتاج إلى تحسين:** من `90%` إلى أقل من `95%`.
- 🔴 **غير مقبول:** أقل من `90%`.

## 🔄 خطة العمل والمتابعة والتصعيد
يتم الاتفاق مع المسؤول المعني على إعداد اتفاقية مستوى الخدمة (SLA) وتحديد مدد زمنية لمعالجة ملاحظات جودة البيانات، مع وضع آلية واضحة للمتابعة والتصعيد في حال عدم المعالجة حسب المتفق عليه وتوضيح المسؤوليات لجميع الأطراف.

### نقاط التحقق (Checkpoints):
- [ ] التأكد من إسناد كل مشكلة إلى مسؤول محدد.
- [ ] تحديث حالة المشكلة في سجل المشكلات بعد التحقق.
- [ ] إعادة فحص البيانات للتأكد من عدم تكرار المشكلة.

### مؤشرات المتابعة (KPIs):
| المؤشر | الغرض من المتابعة |
| :--- | :--- |
| نسبة اكتمال الحقول الأساسية | متابعة تحسن اكتمال البيانات |
| عدد السجلات المكررة | متابعة معالجة التكرار |
| عدد مشكلات الجودة المفتوحة والمغلقة | متابعة تقدم خطة المعالجة |
| عدد المشكلات المتأخرة عن المدة المحددة | متابعة الالتزام بالمدد والتصعيد |
| عدد السجلات التي تمت مطابقتها مع المصدر | متابعة التحقق من الدقة |

## 📑 متطلبات الأعمال والبيانات الوصفية (Metadata)

### متطلبات الأعمال
تُجمع متطلبات الأعمال المقترحة من خلال **مالك البيانات** و**مسؤول جودة البيانات** لتحديد احتياجات العمل، والمشكلات التي تؤثر على الخدمة، والحقول الضرورية لإعداد قواعد قابلة للفحص والمتابعة.

### البيانات الوصفية
تساعد البيانات الوصفية على فهم الحقول وتحديد مصدرها ومالكها وكيفية تحديثها:

| اسم الحقل | المصدر المرجعي | دورية التحديث |
| :--- | :--- | :--- |
| **الرقم الموحد للمنشأة** | مصدر سجل المنشآت المعتمد | عند الإنشاء أو التغيير |
| **رقم الترخيص** | مصدر التراخيص الرسمي المعتمد | عند الإصدار أو التجديد |
| **تاريخ انتهاء الترخيص** | مصدر التراخيص الرسمي المعتمد | عند الإصدار أو التجديد |
| **حالة الترخيص** | مصدر التراخيص الرسمي المعتمد | وفق دورة تحديث الحالة |
| **المدينة** | مصدر بيانات المنشآت المعتمد | عند تغيير الموقع |
| **تاريخ آخر تحديث** | النظام المصدر | حسب سياسة التحديث |
